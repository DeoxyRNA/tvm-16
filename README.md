# TVM-16
TVM-16 (TVM is a Virtual Machine) is a 16-bit virtual ISA, complete with its own assembly language. This repository contains an full implementation of the VM, written in C and C++, as well as a specification document for anyone who wants to implement it in a different language.

In order to translate TVM-16 assembly files into binary executables, you will need an assembler. The official implementation for TAsm can be found here, but the specs document provides details on implementing that too.
